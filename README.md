# ⚔️ 標點符號地下城大冒險 (國小中年級國語科教學遊戲)

專為**國小中年級（三、四年級）**量身打造的國語標點符號沉浸式互動遊戲。將抽象的標點符號語法轉化為趣味生動的「地下城闖關」與「飽足生存」機制，引導學生在緊湊、富有視覺回饋的冒險中，熟練掌握標點符號的正確使用！

---

## 🎮 一、 遊戲核心機制與特色

1. **地下城飢餓度生存機制**：
   - 主角頭頂設有「飢餓值／體力條」，隨時間逐漸減少。
   - 若時間耗盡，主角將會因「體力不支，在地下城餓倒（餓死）」，需重試該小關。
   - 只有推開帶有**正確標點符號**的魔法石門，才能獲得香噴噴的烤雞腿、頂級牛排等食物補充飢餓度！
2. **生動的死亡與學習回饋**：
   - 點選錯誤的石門會觸發隨機死亡事件動畫（**食物中毒**、**地牢怪物偷襲**、**掉入地刺陷阱**、**觸發魔法禁咒**等）。
   - 死亡後立刻彈出**「單格詳解學習卡」**，用適合中年級學童理解的語氣詳細解析該標點的正確規則與常見迷思。
3. **視聽與操作體驗**：
   - 復古 8-Bit 地下城像素氛圍、動態火把光影、可愛冒險者走動與吃食物動畫。
   - 內建 Web Audio API 原生音效（推門聲、咀嚼聲、怪物打擊、通關號角，免下載外部音檔，支援一鍵靜音）。
   - 支援滑鼠點擊與鍵盤數字鍵（1、2、3、4）快速推門。

---

## 🗺️ 二、 關卡與題庫架構 (共 45 題，每小關隨機抽 1 題)

遊戲包含 **3 大關卡**，共 **9 個小關卡**。每題每格均提供 **4 個標點石門選項**：

| 大關卡 | 小關卡 | 題型特色 | 每關總限時 | 時間重置規則 |
| :--- | :--- | :--- | :--- | :--- |
| **第一大關<br>單句句尾標點** | **1-1**：基礎語氣判斷（。？！）<br>**1-2**：進階語氣（反問、催促命令）<br>**1-3**：綜合句尾（含刪節號、破折號） | 單句話，句尾挖空 | **20 秒** | 通過小關卡即重置 |
| **第二大關<br>段落雙格填空** | **2-1**：逗號與頓號區別＋句尾<br>**2-2**：說話提示冒號與引號＋句尾<br>**2-3**：句中轉折逗號／分號＋句尾 | 一段話，包含**句中**與**句尾**兩格 | **40 秒** | **注意：填完第一格不重置時間，完整通過小關才重置** |
| **第三大關<br>短文篇章試煉** | **3-1**：生動冒險故事短文（3格）<br>**3-2**：含書名號、破折號、刪節號（3格）<br>**3-3**：遠古神諭終極試煉（4格） | 中年級適讀短文，數格綜合填空 | **1 分鐘** (60秒) | **注意：連續作答數格，完整通過小關才重置** |

> **題庫數量**：每個小關卡（1-1 至 3-3）均預備了 **5 題獨立題目**，全遊戲共 **45 題**。學生每次挑戰皆隨機抽選，重複遊玩具備高度新鮮感。

## 🏆 三、 排行榜制度 (榮譽榜)

1. **身分登記**：
   - 遊戲開始時，提示學生登記「**班級 座號 姓名**」（例如：`四年三班 12號 林小明`）。
2. **總用時結算機制**：
   - 時間自點擊「開始挑戰」起即刻啟動，直到通過最後 3-3 關卡結算。
   - **包含學生作答錯誤後閱讀「單格詳解」的反思時間**，激勵學生兼顧審慎作答與閱讀理解速度。
   - 依**總通關用時越短者排名越高**（第 1 名 🥇、第 2 名 🥈、第 3 名 🥉）。
   - 排行榜記錄存於瀏覽器本機儲存（LocalStorage），重新整理或隔日上課均會保留。

## 🔒 四、 教師後台管理中心 (數據分析與補救教學)

### 1. 進入方式
- 位於遊戲開始首頁**右上角**的「**🔒 教師後台**」按鈕。
- 點擊後跳出專屬密碼輸入彈窗，需輸入通關密碼：
  $$\mathbf{3.1415926}$$
- 輸入其他任意密碼或錯誤內容，系統將跳出訊息提示：**「你不具備權限」** 並拒絕進入。

### 2. 教師後台功能
- **全體數據總覽**：學生累積觸發錯誤總次數、全通關人次、挑戰總學生數。
- **學生易錯題排行統計（按錯誤次數由高至低）**：
  - 清楚顯示**關卡題號**（如 `2-1 Q2-1-1`）、**題目摘要**、**正確標點**、**錯誤累積次數**與**學生常見誤選符號**。
  - 協助老師一眼看出全班最易錯的盲點，精準進行課堂重點複習。
- **最常混淆之標點符號對照**：分析學生是否習慣將「頓號」錯選成「逗號」，或將「問號」錯選為「句號」。
- **各大關卡錯誤分佈圖**：比對單句、段落、短文三大題型的答對率。
- **最近作答錯誤詳細記錄清單**：記錄每位學生的錯誤時間、誤選門號與死因。
- **匯出 Excel (CSV) 報表**：一鍵下載包含 UTF-8 BOM 的 CSV 檔案，可直接於 Excel 中開啟不亂碼，方便作為學期評量存查。
- **產生模擬數據**：提供示範按鈕，讓教師在尚未有學生作答時即可一鍵預覽後台統計圖表效果。
- **一鍵清除數據**：可於學期初或換班級時重置排行榜與錯題紀錄。

## 🚀 五、 執行方式

1. 本專案為純前端原生架構（HTML5 + CSS3 + Vanilla JavaScript），**無須安裝 Node.js、無須任何後端伺服器**。
2. 只要直接使用瀏覽器（Google Chrome、Microsoft Edge、Safari 等）**按兩下開啟 `index.html`**，即可離線流暢遊玩！
3. 適合在電腦教室、平板載具或教室大螢幕觸控電子白板上進行全班競賽教學。
